# Company Memory by AI 4 SALE: reviewer walkthrough

This walkthrough uses an existing Company Memory account and a prepared demo
workspace. Account registration is not shown. Connection permissions are shown.
The film contains real Codex, Codex CLI, ChatGPT and account-portal recordings.
Processing waits are shortened. Narration uses the founder's authorized voice clone.

## Start here

Open https://memory.ai4.sale/connect and use the dedicated review account supplied
in OpenAI's private Review information fields. Do not use production credentials.
Select **Pilot shared memory**, **General**, and explicitly approve the actions
required by the case. Each client has its own connection. An invitation lets a
second account join the same memory with its own permissions.

The film follows the fictional Aurora website project. Nia is project owner.
The first recorded requirement used "Book a walkthrough" and Nia for enquiries.
The later decision uses "Request pilot access" and Maya for enquiries; Nia remains
project owner. The local implementation in chapter 3 predates that correction.
The film does not claim that changing a memory record automatically deploys a website.

## Replaying the cases

Use fresh conversations and a unique project/run label for new writing tests.
The existing Aurora records are for readback, not evidence that a new test wrote
anything. Do not overwrite the film's records to reproduce a new run.
Create a separate disposable note and client for deletion and revocation.
Use a read-only teammate connection for N02/N03; the writer connection is not
evidence of read-only enforcement.

## Review boundaries

The private Review information supplies service credentials; this public guide
does not contain credentials or authorization-bearing links. A reviewer can use
their own supported OpenAI client. A native CARD runtime, where installed, owns
native task delivery; browser/cloud clients use the server CARD lifecycle.
Never submit a task through both delivery paths.

Free and paid service accounts use their existing permissions. No payment or
real card charge is needed for this walkthrough. The video is supporting evidence,
not an assertion of catalogue approval.
